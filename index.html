The Challenge

From fragmented data to a unified view.

District-level development assessment involves multiple indicators and different data sources. PRISM brings them together into a structured analytical workflow.

01

Fragmented datasets

Socioeconomic, health, demographic, and poverty indicators originate from different sources and need consistent integration.

02

Reliable preparation

District names, missing values, data types, and numerical features must be cleaned before modeling.

03

Interpretable predictions

Classification should be accompanied by feature-importance analysis so contributing indicators can be examined.

01 / Methodology

How PRISM works.

A structured workflow for turning district-level datasets into analyzable features, machine learning outputs, and interpretable findings.

01

Data collection and integration

Load Census 2011, NFHS-5, Multidimensional Poverty Index, and Aspirational Districts data. Create a standardized state-district key for reliable merging.

02

Exploratory data analysis

Examine data types, descriptive statistics, missing values, numerical distributions, correlations, and target-class balance.

03

Data cleaning and feature preparation

Handle missing values, investigate outliers, convert suitable count-based indicators into rates, and remove redundant or unsuitable features.

04

Clustering

Scale the prepared numerical features and use K-Means and hierarchical clustering to identify groups of districts with similar characteristics.

05

Classification

Train Logistic Regression, Random Forest, and Support Vector Machine models to classify districts using the aspirational-status target variable.

06

Evaluation and explainability

Assess model performance with classification metrics and confusion matrices. Analyze feature importance to identify indicators associated with predictions.

02 / Architecture

Three layers. One workflow.

PRISM separates data management, machine learning, and presentation into modular layers to support reproducibility.

LAYER 01

Data layer

Collect and prepare a unified district-level dataset.

  • Census 2011
  • NFHS-5
  • Multidimensional Poverty Index
  • Aspirational Districts list
  • Data cleaning and integration
LAYER 02

Model layer

Analyze patterns, train models, and evaluate results.

  • Exploratory data analysis
  • Data cleaning
  • Feature engineering
  • Clustering
  • Classification
  • Model evaluation
  • Explainability
LAYER 03

Presentation layer

Present district-level results and analytical insights.

  • Charts
  • Tables
  • Cluster summaries
  • Classification reports
  • Feature-importance visualizations
  • Lightweight dashboard

Data and Technology

Built with open-source tools.

The proposed implementation uses Python and commonly used data science libraries.

Data sources

  • Census 2011 Demographic, socioeconomic, workforce, and household indicators.
  • NFHS-5 Health, nutrition, maternal and child health, and sanitation indicators.
  • Multidimensional Poverty Index Poverty measures, including headcount ratio, intensity, and MPI values.
  • Aspirational Districts list Reference classification used to create the target variable.
